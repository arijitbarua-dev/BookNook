# 📚 BookNook

### Discover Books. Borrow Stories. Share Knowledge.

**BookNook** is a modern online library management platform designed to make book discovery and borrowing simple and convenient. It allows users to explore a collection of books, add new books to the library, borrow books for a limited period, keep track of borrowed books, and return them when finished.

With a clean interface and an intuitive user experience, BookNook brings essential library activities together in one digital platform.

---

## ✨ Key Features

- **📖 Explore the Book Collection** — Browse the available library collection and discover books through an organized and user-friendly interface.
- **➕ Add New Books** — Add books to the library and make them available for other readers to explore and borrow.
- **📚 Borrow Books** — Borrow available books for a limited period and enjoy a convenient digital borrowing experience.
- **📋 Track Borrowed Books** — View and manage your borrowed books in one place, making it easier to keep track of your reading activities.
- **↩️ Return Books** — Return borrowed books through the platform, helping keep the library collection updated and available for others.

## 🚀 Getting Started

Follow these steps to run BookNook locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- [MongoDB](https://www.mongodb.com/) or a MongoDB Atlas account, if required by your configuration
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/arijitbarua-dev/BookNook.git
```

**2. Navigate to the project directory**

```bash
cd BookNook
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file in the project root and add the environment variables required by your MongoDB and authentication configuration. Refer to your application configuration for the exact variable names.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```
